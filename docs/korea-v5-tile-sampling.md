# 대한민국 좌표 선택배수 2 (v5)

2026-10-29. 기준 GitHub `main` 커밋 `33088615f1494c4bcf1c9e14da946e384539ea33`에서 알고리즘의 64비트 매핑을 변경한다. 기존 v4의 폴리곤 13,701개, 모든 섬·구멍·원본 정점과 97개 경계 바이너리는 동일하다.

기존 2^32×2^32개의 GRS80 등면적 격자점에 대해 두 번씩 동일한 확률로 선택 기회를 배정한다. 입력 `u64` 상위 18비트 `selector`가 `158226` 이상이면 즉시 거부한다. 그 아래이면 `floor(selector / 2)`번째 오름차순 타일을 선택한다. 타일 위치는 512×512 전체 등면적 격자에서 세로 상위 9비트·가로 상위 9비트이며, 나머지 46비트의 상위 23비트는 세로 인덱스 하위, 하위 23비트는 가로 인덱스 하위에 합친다. 결과인 원래 축당 32비트 인덱스는 변경 없는 `candidate` 함수와 원본 경계 `covers` 판정에 넣는다. 선택값 거부 또는 국토 밖이면 기존 순서대로 새로운 독립 전체 64비트 보완값을 읽는다. 공급 실패, 누락·손상, 취소, 1,024개 보완 한도는 기존 오류 방식대로 처리한다.

`tile-select-v5.bin`은 512×512개 타일에 대한 32,768바이트 비트맵이다. 각 바이트의 비트 번호는 타일 번호의 하위 세 비트다. 낮은 타일 번호부터 0/1을 읽어 1인 번호를 오름차순으로 펼치면 79,113개가 된다. SHA-256은 `492fdbeee7e7a64816d7ea90c57cb5773685fbf96e0b95911a8b7cdcfbf2ae8b`이며, 원본 v4 루트 SHA-256은 `8cb20a5c0da9c3d6225efb0323e24a4f992eb3029a772da3a71a55d3f503bf17`이다. 생성 규칙은 기존 1/32° 지리타일의 `INSIDE`·`MIXED`를 1e-6° 보수적 확장해 512×512 등면적 타일과 교차시키는 것이다. `OUTSIDE`를 국토라고 가정하지 않으며 혼합 셀의 실제 최종 판정은 기존 판정기에 맡긴다. 원래 축당 32비트 격자와 모든 작은 섬의 도달성을 유지한다.

실험 기준 Node v22.16.0의 기존 배포 웹 판정기, 고정 10,000건×5회는 배수 2의 중앙값 5.920초, 기존 6.460초로 8.36% 감소, 실제 `supp` 평균 0.98914 대 2.95564였다. 이는 채택 전 별도 로컬 파일 백엔드·난수 비용 제외 실측이며, 최종 변경 코드의 Rust/브라우저 성능·네트워크 포함 수치라고 표시하지 않는다. 인덱스 데이터 구조와 다운로드 비용은 원본 실험의 316,452바이트 원시 목록에서 현재 32,768바이트 비트맵으로 감소했다.

새 코드로 컴파일·런타임·측정·브라우저 검증이 완료된 범위를 별도 최종 검증 결과에 기입한다. 종전 고정 `num_64 -> 좌표` fixture와 보완 소비 순서는 바뀌는 것이 정상이다. 기존 입력열과 옛 좌표를 계속 일치시킨다고 주장하지 않는다. 배수 2의 균등성은 각 타일에 두 개의 18비트 슬롯이 있고 각 슬롯에 정확히 2^46개 내부 인덱스가 일대일 대응하는 것에서 따라온다. 모든 유효 격자 셀을 포함한 보수적 타일 목록이 완전하다는 것은 원본 상태 분류·수치 경계 안전 여유를 전제로 추가 검증한다.
